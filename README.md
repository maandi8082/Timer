# Study Timer 📚

A web app to track your study sessions and see your progress on a monthly calendar.  
Start a timer, study, then save the session to your personal log – everything is stored locally in your browser.

Timer: https://makrisan.github.io/Timer/

---

## ✨ Features

- **Simple study timer**  
  - Start / pause / reset a session  
  - See today’s total time
  - Can add more details when clicking on the finished and saved sessions

- **Monthly calendar view**  
  - Each day shows the total hours and minutes studied 
  - Click a day to view all sessions from that date  

- **Local storage only**  
  - Your data is stored in the browser (no accounts, no server)  
  - Close the tab and your history is still there when you come back (we love privacy!)

- **Clean, cozy UI**  
  - Soft pink theme that feels friendly, not corporate  
  - Responsive layout that works on desktop and laptop screens
